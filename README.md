#  My First Slack Bot

Hi! This is a simple, friendly Slack bot built with Node.js and the Slack Bolt framework. It runs 24/7 in the cloud so it's always ready to chat and help out!

---

##  What We Used
**Node.js**: The JavaScript engine that runs our code.
**Slack Bolt**: A fun framework to build apps for Slack quickly.
**Systemd**: A tool that keeps our bot running in the background all day and night.
